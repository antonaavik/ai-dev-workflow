---
name: grill-with-docs
description: A relentless interview to sharpen a plan or design, which also creates docs (ADR's and glossary) as we go.
---

Call the Skill tool twice, for "grilling" and "domain-modeling", to load both playbooks.

Run them together: **grilling** is the spine — work the design tree in rounds as it describes. Whenever a round resolves a term or lands a hard-to-reverse trade-off, apply **domain-modeling** _inline_ before moving on — capture the glossary entry in `CONTEXT.md`, and offer an ADR when its three criteria are met. Don't batch the docs to the end; that's what "as we go" means.
